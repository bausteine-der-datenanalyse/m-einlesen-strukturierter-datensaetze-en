# Prerequisites

The processing time for this module is approximately **10 hours**. The following modules are required for working through this module, and the listed libraries are used:

Modules:

- Tool modules: Python, NumPy, Pandas

Packages:

- Module os

- Modules NumPy, numpy.ma

- Module Pandas

  - openpyxl `pip install openpyxl`

  - xlrd `pip install xlrd`

  - pytables `pip install tables`

- Module h5py `pip install h5py`

- Module netCDF4 `pip install netCDF4`

- Module Matplotlib

- Module re (optional)

- Modules datetime, time, pytz, zoneinfo (optional)

The following datasets are used in this unit:

- Tooth growth in guinea pigs [CSV file](https://github.com/vincentarelbundock/Rdatasets/blob/master/csv/datasets/ToothGrowth.csv)

- Electricity market data from the German Federal Network Agency [available here](https://www.smard.de/home/downloadcenter/download-marktdaten/) and from the Austrian Power Grid AG (APG) [available here](https://markttransparenz.apg.at/de/markt/Markttransparenz/erzeugung/Erzeugung-pro-Typ)

- Industrial electricity prices in the member countries of the International Energy Agency [XLS file](https://www.gov.uk/government/uploads/system/uploads/attachment_data/file/670121/table_531.xls)

- Price data of the U.S. stock index S&P500 [XLS file](https://img1.wsimg.com/blobby/go/e5e77e0b-59d1-44d9-ab25-4763ac982e53/downloads/ie_data.xls?ver=1712069253887)

- US State Facts and Figures, retrievable in R

- DSB Accident Atlas from the [Statistical Offices of the Federation and the Länder](https://unfallatlas.statistikportal.de/)

- European gas prices from Eurostat [XLSX file](https://ec.europa.eu/eurostat/statistics-explained/images/3/32/SE_figures_for_Gas_2023S2_v3.xlsx.)

- Building permits, available at the [Federal Statistical Office of Germany](https://www-genesis.destatis.de/datenbank/online/table/31111-0006/sequenz=tabelleErgebnis&selectionname=31111-0006&zeitscheiben=1)

- Sea ice thickness in the Arctic and Antarctic [free NASA Earth registration required](https://nsidc.org/data/ilatm1b/versions/2#anchor-data-access-tools)

- Lightning density [free NASA Earth registration required](https://www.earthdata.nasa.gov/data/catalog/ghrc-daac-lohrfc-2.3.2015)
